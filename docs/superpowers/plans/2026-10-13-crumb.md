# crumb Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build crumb, a Rust Matrix push gateway that receives Push Gateway API requests from any homeserver and forwards them to APNs for Loaf Chat, to spec.

**Architecture:** axum serves `POST /_matrix/push/v1/notify`. The body deserialises straight into validated domain types (`Notification`, `Push`, `Badge`, `Sound`). A `Gateway` fans out to every device concurrently with `join_all`, over one persistent multiplexed HTTP/2 connection per app (hyper-util + rustls), signing with a cached ES256 provider token. In-memory dedupe stops homeserver retries from pinging a phone twice.

**Tech Stack:** Rust 1.96.1 (edition 2024), tokio, axum 0.8, hyper 1 / hyper-util / hyper-rustls (ring), p256 0.14, serde, mise, Podman.

**Spec:** `docs/superpowers/specs/2026-10-13-crumb-design.md`

**Provenance:** Every code block below was compiled and tested in a throwaway crate before this plan was written: 62 tests passed on 8 consecutive runs, clippy was clean with `-D warnings`, and a smoke run reached the real `api.push.apple.com` over TLS + HTTP/2, where Apple parsed the JWT and refused the fake key as expected. Copy the blocks exactly.

## Global Constraints

- **Repo:** `~/code/crumb`, on branch `main`. It has no remote, so nothing is pushed.
- **Toolchain:** Rust is `1.96.1`, pinned in `mise.toml`, with `edition = "2024"`.
- **Dependencies:** exactly those in Task 1's `Cargo.toml`. Never OpenSSL or aws-lc.
- **Never logged:** raw pushkeys (log `Pk(pushkey)`, which prints 8 hex characters of their SHA-256), JWTs, key material, `content`, or any display field (room names, sender names, bodies).
- **APNs endpoints:** the config can name only `production` (`api.push.apple.com`) or `sandbox` (`api.sandbox.push.apple.com`). Plain HTTP exists only through `Origin::from(SocketAddr)`, for tests.
- **Fallback copy:** the title is `Loaf Chat` and the body is `new message`, in lowercase.
- **Alert caps:** titles are at most 200 bytes and bodies at most 2000.
- **Collapse ids:** an `apns-collapse-id` is at most 64 bytes of visible ASCII.
- **JWT timing:** reuse a token for 40 minutes; a forced renewal is suppressed if the current token is under 60 seconds old.
- **Dedupe:** entries live 15 minutes, capped at 100,000 events.
- **Deadline:** 10 seconds per notify request.
- **No `unwrap()` outside tests.** `expect` appears only on proven invariants, each with its reason in a comment or message (four places: payload serialisation, the JWT's header value, the JWT's JSON, and `Origin::from(SocketAddr)`).
- **Shell:** every command must work in Nushell as well as bash.
- **Every task ends with `mise run check` clean:** `cargo fmt --check` passes and clippy reports nothing under `-D warnings`.

## Review Focus

These are the failure modes most likely to bite in production. Each one is pinned by a test in the task that owns the code:

1. **A new connection's first burst can exceed APNs's concurrent-stream limit.** Every device must still be delivered, with no spurious `502`. Pinned in Task 9 by `more_devices_than_apns_allows_streams_all_get_through`, against a fake capped at 8 streams.
2. **APNs can drop the connection between pushes** (a restart, an idle timeout, a GOAWAY). The next push must reconnect and succeed. Pinned in Task 9 by `a_push_after_apns_drops_the_connection_reconnects`.
3. **An event id can be legal JSON but unfit for a header** (non-ASCII, a space). The push must still go out, without a collapse id. Pinned in Task 4 by `collapse_id_needs_at_most_64_visible_ascii_bytes` and in Task 9 by `an_event_id_unfit_for_a_header_is_sent_without_a_collapse_id`.
4. **A homeserver can POST without a `Content-Type`.** It must be processed normally. Pinned in Task 9: the test helper `call` sends none.
5. **A `.p8` can be re-saved with CRLF line endings or without a final newline.** It must still load. Pinned in Task 5 by `a_key_saved_with_crlf_and_no_final_newline_loads`.

```rust
//! An APNs device token: the pushkey of an iOS pusher, as hex.

use std::fmt;

/// A pushkey that is safe to put in an APNs request path: non-empty,
/// even-length ASCII hex. Borrowed, since it only lives for one send.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct DeviceToken<'a>(&'a str);

#[derive(Debug, PartialEq, Eq)]
pub struct NotHex;

impl<'a> TryFrom<&'a str> for DeviceToken<'a> {
    type Error = NotHex;

    fn try_from(s: &'a str) -> Result<Self, Self::Error> {
        let valid =
            !s.is_empty() && s.len().is_multiple_of(2) && s.bytes().all(|b| b.is_ascii_hexdigit());
        if valid { Ok(Self(s)) } else { Err(NotHex) }
    }
}

impl<'a> DeviceToken<'a> {
    pub fn as_str(self) -> &'a str {
        self.0
    }
}

impl fmt::Display for DeviceToken<'_> {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        f.write_str(self.0)
    }
}
```

Put this above the test module in `src/log.rs`:

```rust
//! Pushkeys are APNs device tokens: crumb never logs one. It logs a short
//! hash instead, stable enough to follow one device through the logs.

use std::fmt;

use sha2::{Digest, Sha256};

/// Displays as the first 8 hex characters of SHA-256(pushkey). The hash is
/// only computed if the log line is actually written.
pub struct Pk<'a>(pub &'a str);

impl fmt::Display for Pk<'_> {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        Sha256::digest(self.0.as_bytes())[..4]
            .iter()
            .try_for_each(|b| write!(f, "{b:02x}"))
    }
}
```

```rust
//! The notification as crumb understands it. The wire shape is turned into
//! these types during deserialisation, so the rest of crumb never sees a
//! half-valid notification: a counts-only update cannot carry an alert, a
//! missing count is already zero, and the alert text is already truncated.

use serde::de::{Deserializer, IgnoredAny};
use serde::{Deserialize, Serialize};

/// What the user sees if the app's Notification Service Extension can't
/// run. Lowercase body copy is the app's voice.
const FALLBACK_TITLE: &str = "Loaf Chat";
const FALLBACK_BODY: &str = "new message";

/// Caps that keep the payload under APNs's 4096-byte limit even with the
/// Matrix maximum of 255-byte room and event ids, each sent more than once.
const MAX_TITLE: usize = 200;
const MAX_BODY: usize = 2000;

#[derive(Debug, Deserialize)]
#[serde(from = "RawNotification")]
pub struct Notification {
    pub push: Push,
    pub priority: Priority,
    pub badge: Badge,
    pub devices: Vec<Device>,
}

#[derive(Debug, PartialEq, Eq)]
pub enum Push {
    /// A notification about one event: shown, and rewritten on the phone.
    Event(Event),
    /// The spec's counts-only update: no `event_id`, just a badge refresh.
    Counts,
}

impl Push {
    pub fn event_id(&self) -> Option<&str> {
        match self {
            Push::Event(event) => Some(&event.event_id),
            Push::Counts => None,
        }
    }
}

#[derive(Debug, PartialEq, Eq)]
pub struct Event {
    pub event_id: String,
    pub room_id: Option<String>,
    pub alert: Alert,
}

#[derive(Debug, PartialEq, Eq, Serialize)]
pub struct Alert {
    pub title: String,
    pub body: String,
}

/// The spec's `prio`. Absent means high.
#[derive(Debug, Default, Clone, Copy, PartialEq, Eq, Deserialize)]
#[serde(rename_all = "lowercase")]
pub enum Priority {
    #[default]
    High,
    Low,
}

/// The app icon's number: unread messages plus missed calls.
#[derive(Debug, Default, Clone, Copy, PartialEq, Eq, Serialize)]
#[serde(transparent)]
pub struct Badge(pub u64);

/// The spec omits zero counts, so absent is zero.
#[derive(Debug, Default, Deserialize)]
#[serde(default)]
pub struct Counts {
    pub unread: u64,
    pub missed_calls: u64,
}

impl From<Counts> for Badge {
    fn from(counts: Counts) -> Self {
        Badge(counts.unread.saturating_add(counts.missed_calls))
    }
}

#[derive(Debug, Default, Clone, Copy, PartialEq, Eq)]
pub enum Sound {
    #[default]
    Silent,
    Default,
}

impl Sound {
    /// `aps.sound`. The app ships no sounds named after server values and
    /// iOS plays the default for an unknown name anyway, so say so plainly.
    pub fn apns_name(self) -> Option<&'static str> {
        match self {
            Sound::Silent => None,
            Sound::Default => Some("default"),
        }
    }
}

#[derive(Debug, Deserialize)]
pub struct Device {
    pub app_id: String,
    pub pushkey: String,
    #[serde(default, rename = "tweaks")]
    pub sound: Sound,
}

/// `tweaks` decides only the sound: any `sound` tweak means play one.
impl<'de> Deserialize<'de> for Sound {
    fn deserialize<D: Deserializer<'de>>(d: D) -> Result<Self, D::Error> {
        #[derive(Deserialize)]
        struct Tweaks {
            sound: Option<IgnoredAny>,
        }
        Ok(match Tweaks::deserialize(d)?.sound {
            Some(_) => Sound::Default,
            None => Sound::Silent,
        })
    }
}

/// The spec's `notification`, as sent. Only `devices` is required. Fields
/// crumb has no use for (`pushkey_ts`, `data`) are skipped by serde.
#[derive(Deserialize)]
struct RawNotification {
    event_id: Option<String>,
    room_id: Option<String>,
    #[serde(rename = "type")]
    event_type: Option<String>,
    sender: Option<String>,
    sender_display_name: Option<String>,
    room_name: Option<String>,
    room_alias: Option<String>,
    #[serde(default)]
    user_is_target: bool,
    #[serde(default)]
    prio: Priority,
    content: Option<RawContent>,
    #[serde(default)]
    counts: Counts,
    devices: Vec<Device>,
}

/// Only the two content keys the alert reads. A key of an unexpected type
/// is treated as absent, not as a malformed request: content belongs to
/// the sender, not to the homeserver.
#[derive(Deserialize)]
struct RawContent {
    #[serde(default, deserialize_with = "string_or_none")]
    body: Option<String>,
    #[serde(default, deserialize_with = "string_or_none")]
    membership: Option<String>,
}

fn string_or_none<'de, D: Deserializer<'de>>(d: D) -> Result<Option<String>, D::Error> {
    #[derive(Deserialize)]
    #[serde(untagged)]
    enum Lenient {
        Str(String),
        Other(IgnoredAny),
    }
    Ok(match Lenient::deserialize(d)? {
        Lenient::Str(s) => Some(s),
        Lenient::Other(_) => None,
    })
}

impl From<RawNotification> for Notification {
    fn from(raw: RawNotification) -> Self {
        let push = match raw.event_id {
            None => Push::Counts,
            Some(event_id) => {
                let kind = Kind::new(raw.event_type.as_deref(), raw.content, raw.user_is_target);
                Push::Event(Event {
                    event_id,
                    room_id: raw.room_id,
                    alert: Alert::new(
                        raw.room_name.or(raw.room_alias),
                        raw.sender_display_name.or(raw.sender),
                        kind,
                    ),
                })
            }
        };
        Notification {
            push,
            priority: raw.prio,
            badge: raw.counts.into(),
            devices: raw.devices,
        }
    }
}

/// The event kinds whose alert text crumb can say something useful about.
enum Kind {
    Message(Option<String>),
    Invite,
    Other,
}

impl Kind {
    fn new(event_type: Option<&str>, content: Option<RawContent>, user_is_target: bool) -> Self {
        match (event_type, content) {
            (Some("m.room.message"), content) => Kind::Message(content.and_then(|c| c.body)),
            (Some("m.room.member"), Some(c))
                if user_is_target && c.membership.as_deref() == Some("invite") =>
            {
                Kind::Invite
            }
            _ => Kind::Other,
        }
    }
}

impl Alert {
    /// `room` is the room's name or alias, `sender` the sender's display
    /// name or id. With `event_id_only` the homeserver sends none of these,
    /// which gives the generic fallback.
    fn new(room: Option<String>, sender: Option<String>, kind: Kind) -> Self {
        let body = match kind {
            Kind::Message(Some(text)) => match (&room, &sender) {
                (Some(_), Some(who)) => format!("{who}: {text}"),
                _ => text,
            },
            Kind::Invite => match &sender {
                Some(who) => format!("{who} invited you"),
                None => FALLBACK_BODY.to_owned(),
            },
            Kind::Message(None) | Kind::Other => FALLBACK_BODY.to_owned(),
        };
        let title = room.or(sender).unwrap_or_else(|| FALLBACK_TITLE.to_owned());
        Alert {
            title: truncated(title, MAX_TITLE),
            body: truncated(body, MAX_BODY),
        }
    }
}

/// Cuts `s` in place to at most `max` bytes on a char boundary, ending
/// with an ellipsis.
fn truncated(mut s: String, max: usize) -> String {
    if s.len() > max {
        let mut end = max - '…'.len_utf8();
        while !s.is_char_boundary(end) {
            end -= 1;
        }
        s.truncate(end);
        s.push('…');
    }
    s
}
```

```rust
//! The Push Gateway API's request, response and error bodies.

use axum::Json;
use axum::http::StatusCode;
use axum::response::{IntoResponse, Response};
use serde::{Deserialize, Serialize};
use serde_json::error::Category;

use crate::notification::Notification;

/// The body of `POST /_matrix/push/v1/notify`.
#[derive(Debug, Deserialize)]
pub struct NotifyRequest {
    pub notification: Notification,
}

impl TryFrom<&[u8]> for NotifyRequest {
    type Error = MatrixError;

    /// One pass over the body. serde_json's error category tells "not JSON"
    /// (`M_NOT_JSON`) apart from "the wrong JSON" (`M_BAD_JSON`).
    fn try_from(body: &[u8]) -> Result<Self, Self::Error> {
        serde_json::from_slice(body).map_err(|e| match e.classify() {
            Category::Syntax | Category::Eof | Category::Io => MatrixError::not_json(),
            Category::Data => MatrixError::bad_json(e.to_string()),
        })
    }
}

#[derive(Debug, Serialize)]
pub struct NotifyResponse {
    /// Pushkeys the homeserver must stop using and whose pushers it must
    /// remove.
    pub rejected: Vec<String>,
}

impl IntoResponse for NotifyResponse {
    fn into_response(self) -> Response {
        Json(self).into_response()
    }
}

/// The standard Matrix error: a status plus `{"errcode", "error"}`.
#[derive(Debug, PartialEq, Eq)]
pub struct MatrixError {
    pub status: StatusCode,
    pub errcode: &'static str,
    pub error: String,
}

impl MatrixError {
    pub fn not_json() -> Self {
        Self {
            status: StatusCode::BAD_REQUEST,
            errcode: "M_NOT_JSON",
            error: "Content not JSON.".into(),
        }
    }

    pub fn bad_json(reason: String) -> Self {
        Self {
            status: StatusCode::BAD_REQUEST,
            errcode: "M_BAD_JSON",
            error: reason,
        }
    }

    pub fn unrecognized(status: StatusCode) -> Self {
        Self {
            status,
            errcode: "M_UNRECOGNIZED",
            error: "Unrecognized request".into(),
        }
    }

    /// APNs could not take every push. The spec has the homeserver retry an
    /// HTTP error with backoff; dedupe stops the retry re-pinging devices
    /// that did get it.
    pub fn retry() -> Self {
        Self {
            status: StatusCode::BAD_GATEWAY,
            errcode: "M_UNKNOWN",
            error: "APNs unavailable, try again later.".into(),
        }
    }
}

impl IntoResponse for MatrixError {
    fn into_response(self) -> Response {
        #[derive(Serialize)]
        struct Body<'a> {
            errcode: &'a str,
            error: &'a str,
        }
        let body = Body {
            errcode: self.errcode,
            error: &self.error,
        };
        (self.status, Json(body)).into_response()
    }
}
```

```rust
//! The APNs request for a notification: headers plus the JSON body.
//!
//! The body depends only on the notification and the device's sound, so a
//! request with many devices serialises it at most twice, and every device
//! shares those bytes.

use std::sync::OnceLock;

use bytes::Bytes;
use http::HeaderValue;
use serde::{Serialize, Serializer};

use crate::notification::{Alert, Badge, Notification, Priority, Push, Sound};

/// APNs's limit on `apns-collapse-id`.
const MAX_COLLAPSE_ID: usize = 64;

/// What one device's APNs request carries. Cheap to clone: the header and
/// body are reference-counted.
#[derive(Debug, Clone)]
pub struct ApnsRequest {
    pub priority: Priority,
    pub collapse_id: Option<CollapseId>,
    pub body: Bytes,
}

/// `apns-collapse-id`: the event id, so a homeserver's retry replaces the
/// notification on the phone instead of adding a second one.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct CollapseId(HeaderValue);

/// The event id is too long or not header-safe; the push goes without one.
#[derive(Debug, PartialEq, Eq)]
pub struct NoCollapseId;

impl TryFrom<&str> for CollapseId {
    type Error = NoCollapseId;

    /// Visible ASCII only: HTTP tolerates other bytes in a header, but APNs
    /// promises nothing about them. Real event ids are all ASCII.
    fn try_from(event_id: &str) -> Result<Self, Self::Error> {
        let fits =
            event_id.len() <= MAX_COLLAPSE_ID && event_id.bytes().all(|b| b.is_ascii_graphic());
        if !fits {
            return Err(NoCollapseId);
        }
        HeaderValue::from_str(event_id)
            .map(Self)
            .map_err(|_| NoCollapseId)
    }
}

impl From<CollapseId> for HeaderValue {
    fn from(id: CollapseId) -> Self {
        id.0
    }
}

impl From<Priority> for HeaderValue {
    /// `apns-priority`: 10 sends now, 5 lets the phone save power.
    fn from(priority: Priority) -> Self {
        match priority {
            Priority::High => HeaderValue::from_static("10"),
            Priority::Low => HeaderValue::from_static("5"),
        }
    }
}

/// Builds each device's request from one notification, serialising each
/// distinct body once, on first use.
pub struct Requests<'a> {
    push: &'a Push,
    priority: Priority,
    badge: Badge,
    collapse_id: Option<CollapseId>,
    silent: OnceLock<Bytes>,
    sounding: OnceLock<Bytes>,
}

impl<'a> Requests<'a> {
    pub fn new(push: &'a Push, priority: Priority, badge: Badge) -> Self {
        Self {
            push,
            priority,
            badge,
            collapse_id: push.event_id().and_then(|id| CollapseId::try_from(id).ok()),
            silent: OnceLock::new(),
            sounding: OnceLock::new(),
        }
    }

    pub fn for_device(&self, sound: Sound) -> ApnsRequest {
        // A counts-only update has no sound, so it only ever needs one body.
        let sound = match self.push {
            Push::Event(_) => sound,
            Push::Counts => Sound::Silent,
        };
        let cell = match sound {
            Sound::Silent => &self.silent,
            Sound::Default => &self.sounding,
        };
        ApnsRequest {
            priority: self.priority,
            collapse_id: self.collapse_id.clone(),
            body: cell.get_or_init(|| self.serialise(sound)).clone(),
        }
    }

    fn serialise(&self, sound: Sound) -> Bytes {
        let payload = match self.push {
            Push::Event(event) => Payload::Event {
                aps: EventAps {
                    alert: &event.alert,
                    mutable_content: MutableContent,
                    thread_id: event.room_id.as_deref(),
                    badge: self.badge,
                    sound: sound.apns_name(),
                },
                room_id: event.room_id.as_deref(),
                event_id: &event.event_id,
            },
            Push::Counts => Payload::Counts {
                aps: CountsAps { badge: self.badge },
            },
        };
        // Every field is a string, an integer or a struct of those, which
        // serde_json always serialises: an error here is a bug in this file.
        serde_json::to_vec(&payload)
            .expect("APNs payload types always serialise")
            .into()
    }
}

impl<'a> From<&'a Notification> for Requests<'a> {
    fn from(n: &'a Notification) -> Self {
        Requests::new(&n.push, n.priority, n.badge)
    }
}

#[derive(Serialize)]
#[serde(untagged)]
enum Payload<'a> {
    /// Carries `room_id` and `event_id` at the top level for the app's
    /// Notification Service Extension, which fetches and decrypts the event.
    Event {
        aps: EventAps<'a>,
        #[serde(skip_serializing_if = "Option::is_none")]
        room_id: Option<&'a str>,
        event_id: &'a str,
    },
    Counts {
        aps: CountsAps,
    },
}

#[derive(Serialize)]
struct EventAps<'a> {
    alert: &'a Alert,
    #[serde(rename = "mutable-content")]
    mutable_content: MutableContent,
    /// Groups a room's notifications together.
    #[serde(rename = "thread-id", skip_serializing_if = "Option::is_none")]
    thread_id: Option<&'a str>,
    badge: Badge,
    #[serde(skip_serializing_if = "Option::is_none")]
    sound: Option<&'static str>,
}

#[derive(Serialize)]
struct CountsAps {
    badge: Badge,
}

/// `"mutable-content": 1`, the only value APNs gives meaning to: it routes
/// the notification through the app's extension.
struct MutableContent;

impl Serialize for MutableContent {
    fn serialize<S: Serializer>(&self, s: S) -> Result<S::Ok, S::Error> {
        s.serialize_u8(1)
    }
}
```

```rust
//! APNs provider tokens: ES256 JWTs signed with the app's `.p8` key.
//!
//! Apple rejects a token older than an hour and answers
//! `TooManyProviderTokenUpdates` to one refreshed more often than every 20
//! minutes, so a single token is shared until it is 40 minutes old.

use std::sync::{Arc, RwLock};
use std::time::{SystemTime, UNIX_EPOCH};

use base64::Engine;
use base64::engine::general_purpose::URL_SAFE_NO_PAD;
use http::HeaderValue;
use p256::ecdsa::signature::Signer;
use p256::ecdsa::{Signature, SigningKey};
use serde::Serialize;

use crate::config::{KeyId, TeamId};

/// Renew once a token is this old (seconds): inside Apple's 20–60 minutes.
const MAX_AGE: u64 = 40 * 60;
/// A forced renewal never replaces a token younger than this (seconds), so a
/// burst of `ExpiredProviderToken` answers can't trip
/// `TooManyProviderTokenUpdates`.
const MIN_RENEW_GAP: u64 = 60;

/// Seconds since the Unix epoch. Injected so tests can move time.
pub trait Clock: Send + Sync {
    fn now(&self) -> u64;
}

pub struct SystemClock;

impl Clock for SystemClock {
    fn now(&self) -> u64 {
        SystemTime::now()
            .duration_since(UNIX_EPOCH)
            .map_or(0, |d| d.as_secs())
    }
}

pub struct TokenSource {
    key: SigningKey,
    key_id: KeyId,
    team_id: TeamId,
    clock: Arc<dyn Clock>,
    cached: RwLock<Option<Cached>>,
}

struct Cached {
    /// `bearer <jwt>`, ready for the `authorization` header. Cloning a
    /// `HeaderValue` only bumps a reference count.
    bearer: HeaderValue,
    issued_at: u64,
}

impl TokenSource {
    pub fn new(key: SigningKey, key_id: KeyId, team_id: TeamId, clock: Arc<dyn Clock>) -> Self {
        Self {
            key,
            key_id,
            team_id,
            clock,
            cached: RwLock::new(None),
        }
    }

    /// The shared `authorization` value, renewed once it reaches [`MAX_AGE`].
    pub fn bearer(&self) -> HeaderValue {
        self.bearer_younger_than(MAX_AGE)
    }

    /// APNs called the token expired or invalid: replace it, unless it was
    /// issued within the last minute, in which case it is returned as is.
    pub fn renew(&self) -> HeaderValue {
        self.bearer_younger_than(MIN_RENEW_GAP)
    }

    fn bearer_younger_than(&self, age: u64) -> HeaderValue {
        let now = self.clock.now();
        let fresh = |cached: &Option<Cached>| {
            cached
                .as_ref()
                .filter(|c| now.saturating_sub(c.issued_at) < age)
                .map(|c| c.bearer.clone())
        };
        // Every push takes the read lock; only a renewal takes the write
        // lock. A poisoned lock still holds a valid Option, so keep going.
        if let Some(bearer) = fresh(&self.cached.read().unwrap_or_else(|e| e.into_inner())) {
            return bearer;
        }
        let mut cached = self.cached.write().unwrap_or_else(|e| e.into_inner());
        // Another request may have renewed while this one waited.
        if let Some(bearer) = fresh(&cached) {
            return bearer;
        }
        let bearer = self.sign(now);
        *cached = Some(Cached {
            bearer: bearer.clone(),
            issued_at: now,
        });
        bearer
    }

    fn sign(&self, iat: u64) -> HeaderValue {
        #[derive(Serialize)]
        struct Header<'a> {
            alg: &'static str,
            kid: &'a str,
        }
        #[derive(Serialize)]
        struct Claims<'a> {
            iss: &'a str,
            iat: u64,
        }
        let header = Header {
            alg: "ES256",
            kid: self.key_id.as_str(),
        };
        let claims = Claims {
            iss: self.team_id.as_str(),
            iat,
        };
        let mut jwt = String::with_capacity(256);
        jwt.push_str("bearer ");
        let start = jwt.len();
        encode_json(&header, &mut jwt);
        jwt.push('.');
        encode_json(&claims, &mut jwt);
        // JWS ES256 signs `header.claims` and wants the raw 64-byte r||s.
        let signature: Signature = self.key.sign(&jwt.as_bytes()[start..]);
        jwt.push('.');
        URL_SAFE_NO_PAD.encode_string(signature.to_bytes(), &mut jwt);

        let mut bearer = HeaderValue::try_from(jwt)
            .expect("bearer plus base64url is always a valid header value");
        bearer.set_sensitive(true);
        bearer
    }
}

fn encode_json(value: &impl Serialize, out: &mut String) {
    let json = serde_json::to_vec(value).expect("JWT header and claims always serialise");
    URL_SAFE_NO_PAD.encode_string(json, out);
}
```

```rust
//! The spec requires duplicate suppression by `event_id`: homeservers retry,
//! and a retry must not ping a phone twice. This remembers which devices
//! each event reached, long enough to cover a homeserver's retry backoff.

use std::collections::{HashMap, VecDeque};
use std::sync::{Arc, Mutex};
use std::time::{Duration, Instant};

use crate::token::DeviceToken;

pub struct Dedupe {
    ttl: Duration,
    /// The most events remembered at once.
    cap: usize,
    inner: Mutex<Inner>,
}

#[derive(Default)]
struct Inner {
    /// Keyed by `Arc<str>` so a lookup by `&str` allocates nothing and the
    /// key is shared with `order`.
    events: HashMap<Arc<str>, Delivered>,
    /// Events in first-delivery order. Every entry has the same TTL, so the
    /// front is always the next to expire.
    order: VecDeque<(Arc<str>, Instant)>,
}

struct Delivered {
    at: Instant,
    /// A notification names a handful of devices, so a scan beats hashing.
    pushkeys: Vec<Box<str>>,
}

impl Dedupe {
    pub fn new(ttl: Duration, cap: usize) -> Self {
        Self {
            ttl,
            cap,
            inner: Mutex::default(),
        }
    }

    pub fn contains(&self, event_id: &str, token: DeviceToken<'_>, now: Instant) -> bool {
        self.lock()
            .events
            .get(event_id)
            .filter(|d| now.duration_since(d.at) < self.ttl)
            .is_some_and(|d| d.pushkeys.iter().any(|p| **p == *token.as_str()))
    }

    pub fn insert(&self, event_id: &str, token: DeviceToken<'_>, now: Instant) {
        let mut inner = self.lock();
        let Inner { events, order } = &mut *inner;

        match events.get_mut(event_id) {
            Some(d) if now.duration_since(d.at) < self.ttl => {
                if !d.pushkeys.iter().any(|p| **p == *token.as_str()) {
                    d.pushkeys.push(token.as_str().into());
                }
            }
            _ => {
                let key: Arc<str> = event_id.into();
                events.insert(
                    key.clone(),
                    Delivered {
                        at: now,
                        pushkeys: vec![token.as_str().into()],
                    },
                );
                order.push_back((key, now));
            }
        }

        // Prune here rather than on a timer: no background task to own.
        while let Some((key, at)) = order.front() {
            if now.duration_since(*at) < self.ttl && order.len() <= self.cap {
                break;
            }
            // An event that expired and was delivered again has a newer
            // entry further back; only that entry may remove it.
            if events.get(key).is_some_and(|d| d.at == *at) {
                events.remove(key);
            }
            order.pop_front();
        }
    }

    pub fn len(&self) -> usize {
        self.lock().events.len()
    }

    pub fn is_empty(&self) -> bool {
        self.len() == 0
    }

    fn lock(&self) -> std::sync::MutexGuard<'_, Inner> {
        // A poisoned lock still holds a consistent map: each update above
        // completes before anything can panic.
        self.inner.lock().unwrap_or_else(|e| e.into_inner())
    }
}
```

```rust
//! An APNs client: one persistent HTTP/2 connection per app, with every push
//! multiplexed over it as a stream.

use std::fmt;
use std::sync::Arc;
use std::time::{Duration, SystemTime, UNIX_EPOCH};

use bytes::Bytes;
use http::header::AUTHORIZATION;
use http::{HeaderName, HeaderValue, Request, StatusCode, Uri};
use http_body_util::{BodyExt, Full};
use hyper_rustls::{HttpsConnector, HttpsConnectorBuilder};
use hyper_util::client::legacy::Client;
use hyper_util::client::legacy::connect::HttpConnector;
use hyper_util::rt::{TokioExecutor, TokioTimer};
use serde::Deserialize;
use tracing::warn;

use crate::config::{AppConfig, Origin};
use crate::jwt::{SystemClock, TokenSource};
use crate::log::Pk;
use crate::payload::ApnsRequest;
use crate::token::DeviceToken;

const APNS_TOPIC: HeaderName = HeaderName::from_static("apns-topic");
const APNS_PUSH_TYPE: HeaderName = HeaderName::from_static("apns-push-type");
const APNS_PRIORITY: HeaderName = HeaderName::from_static("apns-priority");
const APNS_EXPIRATION: HeaderName = HeaderName::from_static("apns-expiration");
const APNS_COLLAPSE_ID: HeaderName = HeaderName::from_static("apns-collapse-id");
const APNS_ID: HeaderName = HeaderName::from_static("apns-id");
const ALERT: HeaderValue = HeaderValue::from_static("alert");

/// How long APNs keeps trying to reach an offline phone.
const EXPIRY: Duration = Duration::from_secs(24 * 60 * 60);
/// Pings that notice a dead idle connection before a push has to.
const KEEP_ALIVE: Duration = Duration::from_secs(60);
/// How often one push may be re-sent after APNs refuses its stream. A new
/// connection's first burst can outrun the server's stream limit; once its
/// SETTINGS arrive, h2 queues streams over the limit itself.
const MAX_REFUSALS: u32 = 3;

/// What became of one push.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Outcome {
    Delivered,
    /// The token is dead for good: the homeserver must drop the pusher.
    Rejected,
    /// Worth retrying later.
    Transient,
}

/// APNs's answer to one request, before crumb decides what to do about it.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Verdict {
    Delivered,
    Rejected,
    /// The provider token is stale: renew it and send once more.
    RenewToken,
    Transient,
}

/// The `reason` APNs gives with an error. Only the reasons crumb acts on are
/// named; the rest are transient.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Deserialize)]
pub enum Reason {
    BadDeviceToken,
    DeviceTokenNotForTopic,
    Unregistered,
    ExpiredProviderToken,
    InvalidProviderToken,
    #[serde(other)]
    Other,
}

impl From<(StatusCode, Option<Reason>)> for Verdict {
    fn from((status, reason): (StatusCode, Option<Reason>)) -> Self {
        match (status, reason) {
            (StatusCode::OK, _) => Verdict::Delivered,
            (StatusCode::GONE, _)
            | (
                StatusCode::BAD_REQUEST,
                Some(Reason::BadDeviceToken | Reason::DeviceTokenNotForTopic),
            ) => Verdict::Rejected,
            (
                StatusCode::FORBIDDEN,
                Some(Reason::ExpiredProviderToken | Reason::InvalidProviderToken),
            ) => Verdict::RenewToken,
            _ => Verdict::Transient,
        }
    }
}

impl From<Verdict> for Outcome {
    /// Once a renewal has been tried, a stale token is just transient.
    fn from(verdict: Verdict) -> Self {
        match verdict {
            Verdict::Delivered => Outcome::Delivered,
            Verdict::Rejected => Outcome::Rejected,
            Verdict::RenewToken | Verdict::Transient => Outcome::Transient,
        }
    }
}

type HttpClient = Client<HttpsConnector<HttpConnector>, Full<Bytes>>;

pub struct ApnsClient {
    http: HttpClient,
    origin: Origin,
    topic: HeaderValue,
    tokens: TokenSource,
}

impl From<AppConfig> for ApnsClient {
    fn from(app: AppConfig) -> Self {
        let tokens = TokenSource::new(app.key, app.key_id, app.team_id, Arc::new(SystemClock));
        ApnsClient::new(app.endpoint.into(), app.topic.into(), tokens)
    }
}

impl ApnsClient {
    pub fn new(origin: Origin, topic: HeaderValue, tokens: TokenSource) -> Self {
        // HTTP/2 only, as APNs requires. Plain HTTP is allowed so a test can
        // reach a fake APNs; an Origin from the config is always HTTPS.
        let connector = HttpsConnectorBuilder::new()
            .with_webpki_roots()
            .https_or_http()
            .enable_http2()
            .build();
        let http = Client::builder(TokioExecutor::new())
            .timer(TokioTimer::new())
            .http2_only(true)
            .http2_keep_alive_interval(KEEP_ALIVE)
            .http2_keep_alive_while_idle(true)
            .build(connector);
        Self {
            http,
            origin,
            topic,
            tokens,
        }
    }

    pub async fn send(&self, token: DeviceToken<'_>, request: &ApnsRequest) -> Outcome {
        let mut renewed = false;
        let mut refusals = 0;
        loop {
            let bearer = if renewed {
                self.tokens.renew()
            } else {
                self.tokens.bearer()
            };
            match self.post(token, request, bearer).await {
                Ok(Verdict::RenewToken) if !renewed => renewed = true,
                Ok(verdict) => return verdict.into(),
                // A refused stream was never processed, so sending it again
                // can't notify twice (RFC 9113, section 8.7).
                Err(e) if e.is_refused_stream() && refusals < MAX_REFUSALS => refusals += 1,
                Err(e) => {
                    warn!(pk = %Pk(token.as_str()), error = %e, "APNs request failed");
                    return Outcome::Transient;
                }
            }
        }
    }

    async fn post(
        &self,
        token: DeviceToken<'_>,
        request: &ApnsRequest,
        bearer: HeaderValue,
    ) -> Result<Verdict, SendError> {
        let uri = Uri::builder()
            .scheme(self.origin.scheme.clone())
            .authority(self.origin.authority.clone())
            .path_and_query(format!("/3/device/{token}"))
            .build()?;
        let mut builder = Request::post(uri)
            .header(AUTHORIZATION, bearer)
            .header(APNS_TOPIC, self.topic.clone())
            .header(APNS_PUSH_TYPE, ALERT)
            .header(APNS_PRIORITY, HeaderValue::from(request.priority))
            .header(APNS_EXPIRATION, expiration());
        if let Some(id) = &request.collapse_id {
            builder = builder.header(APNS_COLLAPSE_ID, HeaderValue::from(id.clone()));
        }
        let response = self
            .http
            .request(builder.body(Full::new(request.body.clone()))?)
            .await?;

        let status = response.status();
        if status == StatusCode::OK {
            return Ok(Verdict::Delivered);
        }
        let apns_id = response.headers().get(APNS_ID).cloned();
        let body = response.into_body().collect().await?.to_bytes();
        let reason = serde_json::from_slice::<ErrorBody>(&body)
            .ok()
            .map(|b| b.reason);
        let verdict = Verdict::from((status, reason));
        warn!(
            pk = %Pk(token.as_str()),
            status = status.as_u16(),
            ?reason,
            apns_id = ?apns_id,
            ?verdict,
            "APNs refused a push"
        );
        Ok(verdict)
    }
}

#[derive(Deserialize)]
struct ErrorBody {
    reason: Reason,
}

/// `apns-expiration`, as Unix seconds.
fn expiration() -> HeaderValue {
    let at = SystemTime::now() + EXPIRY;
    HeaderValue::from(at.duration_since(UNIX_EPOCH).map_or(0, |d| d.as_secs()))
}

#[derive(Debug)]
enum SendError {
    Request(http::Error),
    Connection(hyper_util::client::legacy::Error),
    Body(hyper::Error),
}

impl SendError {
    fn is_refused_stream(&self) -> bool {
        let SendError::Connection(e) = self else {
            return false;
        };
        let mut source = std::error::Error::source(e);
        while let Some(e) = source {
            if let Some(h2) = e.downcast_ref::<h2::Error>() {
                return h2.reason() == Some(h2::Reason::REFUSED_STREAM);
            }
            source = e.source();
        }
        false
    }
}

impl From<http::Error> for SendError {
    fn from(e: http::Error) -> Self {
        SendError::Request(e)
    }
}

impl From<hyper_util::client::legacy::Error> for SendError {
    fn from(e: hyper_util::client::legacy::Error) -> Self {
        SendError::Connection(e)
    }
}

impl From<hyper::Error> for SendError {
    fn from(e: hyper::Error) -> Self {
        SendError::Body(e)
    }
}

impl fmt::Display for SendError {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        match self {
            SendError::Request(e) => write!(f, "building the request: {e}"),
            SendError::Connection(e) => {
                write!(f, "connection: {e}")?;
                let mut source = std::error::Error::source(e);
                while let Some(e) = source {
                    write!(f, ": {e}")?;
                    source = e.source();
                }
                Ok(())
            }
            SendError::Body(e) => write!(f, "reading the response: {e}"),
        }
    }
}
```

```rust
pub const APP_ID: &str = "moe.loaf.chat.ios";

#[derive(Debug, Clone, Copy)]
pub enum Reply {
    Ok,
    Error(u16, &'static str),
    /// Never answer.
    Stall,
}

#[derive(Debug, Clone)]
pub struct Seen {
    pub token: String,
    pub headers: HeaderMap,
    pub body: Value,
}

#[derive(Default)]
struct State {
    seen: Mutex<Vec<Seen>>,
    replies: Mutex<HashMap<String, VecDeque<Reply>>>,
    connections: AtomicUsize,
    /// Aborting these drops every open connection, like an APNs restart.
    tasks: Mutex<Vec<tokio::task::AbortHandle>>,
}

pub struct FakeApns {
    pub addr: SocketAddr,
    state: Arc<State>,
}

impl FakeApns {
    pub async fn start() -> Self {
        Self::start_with_streams(None).await
    }

    /// `streams` caps concurrent streams per connection, as APNs does.
    pub async fn start_with_streams(streams: Option<u32>) -> Self {
        let listener = TcpListener::bind("127.0.0.1:0").await.unwrap();
        let addr = listener.local_addr().unwrap();
        let state = Arc::new(State::default());
        let server_state = state.clone();
        tokio::spawn(async move {
            loop {
                let (stream, _) = listener.accept().await.unwrap();
                server_state.connections.fetch_add(1, Ordering::SeqCst);
                let state = server_state.clone();
                let task = tokio::spawn(async move {
                    let service = service_fn(move |req| answer(state.clone(), req));
                    let _ = hyper::server::conn::http2::Builder::new(TokioExecutor::new())
                        .max_concurrent_streams(streams)
                        .serve_connection(TokioIo::new(stream), service)
                        .await;
                });
                server_state.tasks.lock().unwrap().push(task.abort_handle());
            }
        });
        Self { addr, state }
    }

    /// Queues replies for a token; once they run out it gets 200.
    pub fn script(&self, token: &str, replies: impl IntoIterator<Item = Reply>) {
        self.state
            .replies
            .lock()
            .unwrap()
            .entry(token.to_owned())
            .or_default()
            .extend(replies);
    }

    pub fn seen(&self) -> Vec<Seen> {
        self.state.seen.lock().unwrap().clone()
    }

    pub fn seen_for(&self, token: &str) -> Vec<Seen> {
        self.seen()
            .into_iter()
            .filter(|s| s.token == token)
            .collect()
    }

    pub fn connections(&self) -> usize {
        self.state.connections.load(Ordering::SeqCst)
    }

    pub fn drop_connections(&self) {
        for task in self.state.tasks.lock().unwrap().drain(..) {
            task.abort();
        }
    }
}

async fn answer(
    state: Arc<State>,
    req: Request<hyper::body::Incoming>,
) -> Result<Response<Full<Bytes>>, Infallible> {
    let token = req
        .uri()
        .path()
        .strip_prefix("/3/device/")
        .unwrap_or_default()
        .to_owned();
    let headers = req.headers().clone();
    let body = req.into_body().collect().await.unwrap().to_bytes();
    state.seen.lock().unwrap().push(Seen {
        token: token.clone(),
        headers,
        body: serde_json::from_slice(&body).unwrap(),
    });
    let reply = state
        .replies
        .lock()
        .unwrap()
        .get_mut(&token)
        .and_then(VecDeque::pop_front)
        .unwrap_or(Reply::Ok);
    let response = match reply {
        Reply::Ok => Response::new(Full::default()),
        Reply::Error(status, reason) => Response::builder()
            .status(status)
            .header("apns-id", "00000000-0000-0000-0000-000000000000")
            .body(Full::new(format!(r#"{{"reason":"{reason}"}}"#).into()))
            .unwrap(),
        Reply::Stall => {
            tokio::time::sleep(Duration::from_secs(3600)).await;
            unreachable!()
        }
    };
    Ok(response)
}
```

```rust
//! One notify request: fan out to every device, then answer the homeserver.

use std::collections::HashMap;
use std::time::{Duration, Instant};

use axum::response::{IntoResponse, Response};
use futures_util::future::join_all;
use tracing::{debug, info, warn};

use crate::apns::{ApnsClient, Outcome};
use crate::dedupe::Dedupe;
use crate::log::Pk;
use crate::matrix::{MatrixError, NotifyResponse};
use crate::notification::{Device, Notification, Push};
use crate::payload::Requests;
use crate::token::DeviceToken;

pub struct Gateway {
    apps: HashMap<String, ApnsClient>,
    dedupe: Dedupe,
    /// The most a homeserver waits for an answer.
    deadline: Duration,
}

/// The answer to a notify request.
#[derive(Debug, PartialEq, Eq)]
pub enum Dispatch {
    /// Every device was settled; these pushkeys are dead.
    Done { rejected: Vec<String> },
    /// At least one device may still get it on a retry.
    Retry,
}

impl IntoResponse for Dispatch {
    fn into_response(self) -> Response {
        match self {
            Dispatch::Done { rejected } => NotifyResponse { rejected }.into_response(),
            Dispatch::Retry => MatrixError::retry().into_response(),
        }
    }
}

impl Gateway {
    pub fn new(apps: HashMap<String, ApnsClient>, dedupe: Dedupe, deadline: Duration) -> Self {
        Self {
            apps,
            dedupe,
            deadline,
        }
    }

    pub async fn notify(&self, notification: Notification) -> Dispatch {
        let Notification {
            push,
            priority,
            badge,
            devices,
        } = notification;
        let requests = Requests::new(&push, priority, badge);

        // Every device is sent concurrently from this one task: the futures
        // borrow the notification, and the shared HTTP/2 connection carries
        // them as parallel streams.
        let sends = devices.iter().map(|d| self.deliver(&push, &requests, d));
        let Ok(outcomes) = tokio::time::timeout(self.deadline, join_all(sends)).await else {
            warn!(devices = devices.len(), "APNs missed the deadline");
            return Dispatch::Retry;
        };

        let mut rejected = Vec::new();
        let mut retry = false;
        for (device, outcome) in devices.into_iter().zip(outcomes) {
            match outcome {
                Outcome::Delivered => {}
                Outcome::Rejected => rejected.push(device.pushkey),
                Outcome::Transient => retry = true,
            }
        }
        if retry {
            Dispatch::Retry
        } else {
            Dispatch::Done { rejected }
        }
    }

    async fn deliver(&self, push: &Push, requests: &Requests<'_>, device: &Device) -> Outcome {
        let pk = Pk(&device.pushkey);
        let Some(client) = self.apps.get(&device.app_id) else {
            info!(%pk, app_id = %device.app_id, "unknown app_id, rejected");
            return Outcome::Rejected;
        };
        let Ok(token) = DeviceToken::try_from(device.pushkey.as_str()) else {
            info!(%pk, app_id = %device.app_id, "pushkey is not a device token, rejected");
            return Outcome::Rejected;
        };
        let event_id = push.event_id();
        if let Some(event_id) = event_id
            && self.dedupe.contains(event_id, token, Instant::now())
        {
            debug!(%pk, "already delivered");
            return Outcome::Delivered;
        }

        let outcome = client.send(token, &requests.for_device(device.sound)).await;
        if outcome == Outcome::Delivered
            && let Some(event_id) = event_id
        {
            self.dedupe.insert(event_id, token, Instant::now());
        }
        info!(%pk, app_id = %device.app_id, ?outcome, "push");
        outcome
    }
}
```

```rust
//! The HTTP surface: the notify endpoint, a health check, and the spec's
//! `M_UNRECOGNIZED` for everything else.

use std::sync::Arc;

use axum::Router;
use axum::body::Bytes;
use axum::extract::State;
use axum::http::{StatusCode, header};
use axum::response::{IntoResponse, Response};
use axum::routing::{get, post};

use crate::dispatch::Gateway;
use crate::matrix::{MatrixError, NotifyRequest};

pub const NOTIFY_PATH: &str = "/_matrix/push/v1/notify";

pub fn router(gateway: Arc<Gateway>) -> Router {
    Router::new()
        .route(NOTIFY_PATH, post(notify))
        .route("/health", get(health))
        .fallback(|| async { MatrixError::unrecognized(StatusCode::NOT_FOUND) })
        .method_not_allowed_fallback(|| async {
            MatrixError::unrecognized(StatusCode::METHOD_NOT_ALLOWED)
        })
        .with_state(gateway)
}

/// Takes the raw body so a malformed one gets the Matrix error shape rather
/// than axum's own rejection, and regardless of `Content-Type`.
async fn notify(State(gateway): State<Arc<Gateway>>, body: Bytes) -> Response {
    match NotifyRequest::try_from(&body[..]) {
        Ok(request) => gateway.notify(request.notification).await.into_response(),
        Err(e) => e.into_response(),
    }
}

async fn health() -> impl IntoResponse {
    ([(header::CONTENT_TYPE, "application/json")], "{}")
}
```

```rust
use std::collections::HashMap;
use std::process::ExitCode;
use std::sync::Arc;
use std::time::Duration;

use crumb::apns::ApnsClient;
use crumb::config::Config;
use crumb::dedupe::Dedupe;
use crumb::dispatch::Gateway;
use crumb::server::router;
use tokio::net::TcpListener;
use tracing::{error, info};
use tracing_subscriber::EnvFilter;

/// Longer than any sensible homeserver retry backoff.
const DEDUPE_TTL: Duration = Duration::from_secs(15 * 60);
const DEDUPE_CAP: usize = 100_000;
/// The most a homeserver waits for an answer.
const DEADLINE: Duration = Duration::from_secs(10);

#[tokio::main]
async fn main() -> ExitCode {
    tracing_subscriber::fmt()
        .with_env_filter(
            EnvFilter::try_from_default_env().unwrap_or_else(|_| EnvFilter::new("crumb=info")),
        )
        .init();

    match run().await {
        Ok(()) => ExitCode::SUCCESS,
        Err(e) => {
            error!("{e}");
            ExitCode::FAILURE
        }
    }
}

async fn run() -> Result<(), Box<dyn std::error::Error>> {
    let path = std::env::var_os("CRUMB_CONFIG").ok_or("CRUMB_CONFIG is not set")?;
    let config = Config::load(path.as_ref())?;

    let apps: HashMap<String, ApnsClient> = config
        .apps
        .into_iter()
        .map(|(app_id, app)| {
            info!(%app_id, endpoint = ?app.endpoint, "serving app");
            (app_id, ApnsClient::from(app))
        })
        .collect();
    let gateway = Arc::new(Gateway::new(
        apps,
        Dedupe::new(DEDUPE_TTL, DEDUPE_CAP),
        DEADLINE,
    ));

    let listener = TcpListener::bind(config.listen).await?;
    info!(listen = %config.listen, "crumb is up");
    axum::serve(listener, router(gateway))
        .with_graceful_shutdown(shutdown())
        .await?;
    Ok(())
}

/// Podman stops a container with SIGTERM; a terminal sends SIGINT.
async fn shutdown() {
    let interrupt = tokio::signal::ctrl_c();
    #[cfg(unix)]
    {
        let mut term =
            match tokio::signal::unix::signal(tokio::signal::unix::SignalKind::terminate()) {
                Ok(term) => term,
                Err(e) => {
                    error!("cannot listen for SIGTERM: {e}");
                    let _ = interrupt.await;
                    return;
                }
            };
        tokio::select! {
            _ = interrupt => {}
            _ = term.recv() => {}
        }
    }
    #[cfg(not(unix))]
    let _ = interrupt.await;
    info!("shutting down");
}
```

````markdown
# crumb

A [Matrix push gateway](https://spec.matrix.org/latest/push-gateway-api/)
for Loaf Chat. Homeservers POST notifications to it, and it forwards them to
Apple's APNs over one persistent HTTP/2 connection per app.

Loaf Chat's pushers point at
`https://push.matrix.loaf.moe/_matrix/push/v1/notify`.

## Configure

crumb reads a TOML file named by `CRUMB_CONFIG`. See
[`crumb.example.toml`](crumb.example.toml). At startup it checks every app
and reads every key, and exits with a message naming the app and the field if
anything is wrong.

The `.p8` key is a secret. Mount it read-only. crumb never logs it, never
logs a pushkey (only `pk=` plus 8 hex characters of its SHA-256), and never
logs message content.

## Run

```nu
CRUMB_CONFIG=crumb.toml cargo run --release
```

`RUST_LOG` overrides the log filter, which defaults to `crumb=info`.

## Container

```nu
podman build -t crumb .
```

Then run it as follows. The paths are examples.

```nu
(podman run --rm -p 8080:8080
  -v ./crumb.toml:/etc/crumb.toml:ro
  -v ./AuthKey.p8:/run/secrets/apns.p8:ro
  -e CRUMB_CONFIG=/etc/crumb.toml
  crumb)
```

The image is distroless and runs as a non-root user. It listens on 8080 and
speaks plain HTTP.

## Behind Traefik

Route `Host(push.matrix.loaf.moe) && PathPrefix(/_matrix/push/)` to the
container's port 8080, and terminate TLS there. The endpoint needs no
authentication and has no rate limit, as the spec says; add a Traefik
rate-limit middleware if that ever matters.

`GET /health` answers `200 {}`, for a Traefik health check. There is no shell
in the image, so check health from Traefik, not from inside the container.

## Smoke test

```nu
(http post --content-type application/json
  http://localhost:8080/_matrix/push/v1/notify
  { notification: { event_id: '$smoke', room_id: '!smoke:example.org',
    devices: [{ app_id: 'moe.loaf.chat.ios', pushkey: '00' }] } })
```

With a real device token as the `pushkey`, the phone shows a notification.
With `00`, APNs refuses the token, and the answer is `{"rejected": ["00"]}`.
````
